# 展示乐谱

这里是四首为公开展示重新写作的小曲。上一级目录的短示例保留作快速入门和既有验收，不再用来代表套件的编曲效果。

| 曲目 | 主体 | 编制与结构 |
|---|---|---|
| [Window Light / 窗边微光](window-light.json) | 16 小节，92 BPM，41.74 秒 | D 大调钢琴；右手主题、左手分解和弦、内声部；问句→答句→升高音区的桥段→回归与终止 |
| [Pocket Workshop / 律动工坊](pocket-workshop.json) | 16 小节，108 BPM，35.56 秒 | AVL Red Zeppelin；切分底鼓、轻重军鼓与轻微摇摆镲片；两小节收敛段后回归，句尾过门和完整结束 |
| [Morning Path / 林间晨行](morning-path.json) | 12 小节，88 BPM，32.73 秒 | G 大调；长笛提问、小号回应，弦乐从长音转为分拍推进；高潮后终止于主和弦 |
| [After Hours / 夜航](after-hours.json) | 16 小节，112 BPM，34.29 秒 | D 小调电子；两小节引入→主题→变奏→两小节间奏→高音区回归→属和弦解决 |

播放与修改入口见 [展示页](../../docs/DEMOS.md)。JSON 是可以直接运行和编辑的完整乐谱，保留分轨与 MIDI。`compose.py` 保存和声、旋律、力度、微小时序偏移和段落安排；使用 Python 运行会重新生成这四份 JSON，因此手改 JSON 后不要无意间重新运行它。

演奏处理：钢琴逐小节更换踏板，旋律与伴奏分别控制力度；鼓组交替重音、ghost notes 和过门均明确写入；管弦按现有持续音音源写作，未虚构 keyswitch 或 expression 能力；电子段落通过不同乐器进出制造对比，不改变未经验证的插件参数。

所有曲目为项目原创示例，适用项目 MIT。音源内容保留各自许可，鸣谢见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。
